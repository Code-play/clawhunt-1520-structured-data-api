==============================================================================
1. 三层只读防线（逐层单独取证）
==============================================================================

1.1 第一层-a：只读连接 file:...?mode=ro（SQLite 文件层面就没有写权限）
  INSERT  blocked=true  E_DB_READONLY: attempt to write a readonly database
  UPDATE  blocked=true  E_DB_READONLY: attempt to write a readonly database
  DELETE  blocked=true  E_DB_READONLY: attempt to write a readonly database
  DROP    blocked=true  E_DB_READONLY: attempt to write a readonly database

1.2 第一层-b：可写连接先执行 PRAGMA query_only=ON，再尝试写入
  INSERT  blocked=true  E_DB_READONLY: attempt to write a readonly database

1.3 第一层-c：可写连接 + sqlite3 set_authorizer 回调（非 SELECT 动作在 prepare 阶段被拒）
  INSERT  blocked=true  E_SQL_AUTHORIZER: not authorized（被拒动作 SQLITE_INSERT）
  UPDATE  blocked=true  E_SQL_AUTHORIZER: not authorized（被拒动作 SQLITE_UPDATE）
  DELETE  blocked=true  E_SQL_AUTHORIZER: not authorized（被拒动作 SQLITE_DELETE）
  DROP    blocked=true  E_SQL_AUTHORIZER: not authorized（被拒动作 SQLITE_DELETE）
  事实表行数不变：4000 行（写操作一条都没落地）

1.4 第二层：语句白名单（解析层，未连接数据库即可判定）
  允许  SELECT region, SUM(orders) AS orders FROM v_sales_daily    允许：first_keyword=SELECT views=v_sales_daily
  允许  WITH t AS (SELECT region, SUM(revenue_cents) AS r FROM v   允许：first_keyword=WITH views=v_sales_daily,t
  拒绝  DELETE FROM fact_sales                                     E_SQL_NOT_ALLOWED: 语句必须以 SELECT 或 WITH 开头，实际首关键字是 DELETE
  拒绝  DROP TABLE fact_sales                                      E_SQL_NOT_ALLOWED: 语句必须以 SELECT 或 WITH 开头，实际首关键字是 DROP
  拒绝  PRAGMA table_info(fact_sales)                              E_SQL_NOT_ALLOWED: 语句必须以 SELECT 或 WITH 开头，实际首关键字是 PRAGMA
  拒绝  SELECT 1; DELETE FROM fact_sales                           E_SQL_MULTI_STATEMENT: 检测到 2 条语句，一条请求只允许一条只读语句
  拒绝  SELECT * FROM fact_sales -- 注释注入                           E_SQL_COMMENT: 语句中不允许出现注释（-- 注释注入），拒绝执行
  拒绝  SELECT * FROM secret_salary_table                          E_VIEW_NOT_ALLOWED: 语句引用了白名单之外的视图/表：secret_salary_table；允许：v_category_revenue, v_channel_daily, v_product_rank, v_sales_daily, v_sales_enriched, v_segment_summary

1.5 第三层：行数与超时上限
  行数上限 5：返回 5 行，truncated=true（明细查询本身不写 LIMIT）
  行数超限：拒绝 E_ROW_LIMIT（参数 limit=100000 超过上限 100（模板 sales_line_sample 上限 100 行，全局硬上限 200 行））
  超时上限 150ms：blocked=true，连接仍可用=true（E_TIMEOUT: 查询超过时间上限，被中断（progress handler））

  取证条目：L1=9  L2=8  L3=3  合计=20
  L1 全部拒写：True
